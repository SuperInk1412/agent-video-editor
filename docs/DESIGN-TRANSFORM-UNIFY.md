## 1. 投屏修正（第一步）

### 1.1 出画与投屏分开
- 最终画面显示哪台相机，**只看相机栈原有规则**：顺序、片段时间、可见（眼睛）、不透明度。和这台相机有没有投屏元素无关。
- **去掉 `cam.output`（"仅投屏"）**。只给投屏供画面的相机，用户把它隐藏、或者放到不出画的时间段即可；隐藏的相机照样能当投屏来源。
- "仅投屏"标记改成只用来提示的角标，比如"被投屏 ×2"。
- 投屏的主要用途是场景里的屏幕：回忆长廊、多视角分屏、画中画、"镜头从电视里拍出来"。全屏拍屏只在特殊需要时由用户手动搭，编辑器**不会自动生成**这种结构。

### 1.2 贴屏迁移重做（替换 HUD 机位）
- 打开旧项目时，贴屏元素按镜头切分：跨了几个镜头的，就在切镜头的时间点切成几段；每段用**空间父级**挂到那一段的镜头相机上（跟随位置和旋转）。不生成投屏，不生成 HUD 机位。
- 已经被 HUD 方案迁移并存过盘的项目（有 `ob_hud` 空元素、`cam_hud` 相机，以及挂在它下面的 `el_feed_*` 投屏）：打开时还原，再按上面的方式迁移。
- 局限：镜头的 FOV 在动时，字幕大小会跟着变（以前的贴屏也是这样），迁移报告会列出受影响的镜头。

### 1.3 投屏的本质（不变）
2D 元素 `type:'camfeed'`、`el.feed = {camera, delay}`：一块没有厚度的平面，贴图是来源相机的原始画面（不含全局后期）；自发光、不受雾影响、两面都能看到。

### 1.4 投屏导航与相机跟随（交互，用户 2026-10-28 定稿）

| 操作 | 结果 |
|---|---|
| 选中一台相机，按 **F5** | 进入编辑模式的**选择模式**，视角**跟随**这台相机：相机运镜时视角一起动，仍然可以点选、拖动元素 |
| 编辑模式下**双击投屏** | 跟随这块投屏的来源相机，等同于选中来源相机再按 F5 |
| 预览模式下**双击投屏** | 自动进入编辑模式的选择模式，并跟随来源相机 |
| 时间轴里右键**相机**或**投屏元素**，选"跟随此相机"或"跟随投屏来源" | 同上 |
| 属性面板里投屏元素的"来源相机 [跟随]" | 同上 |
| 切到**移动模式** | 脱离跟随，从当前位置开始自由移动 |
| 按住 **F3** | 高亮视野里的投屏平面：边框，加"投屏 · 来源相机名"，上一帧投屏另标"上一帧" |

- 开始跟随时，如果播放头不在这台相机的时间段内，自动跳到这台相机的起点。
- 跟随状态下播放，播到这台相机的时间段结束时**自动暂停**。
- 选中相机时，属性面板列出"这台相机的投屏"，点一下就飞到那块屏幕前（这时不跟随）。
- 不做面包屑；不做视角后退键（选相机按 F5、或者退出编辑模式，就能回到想要的画面）。
- 文字压在投屏上时，双击编辑文字（光标下最上层的元素优先）。投屏画面里嵌套的投屏只是像素，要先跟随外层的来源相机才能操作。

## 2. 三轴旋转（第二步）

- **所有元素都用 `rotation.x / rotation.y / rotation.z`**（度），包括 2D 元素、3D 物体、相机。每个轴单独打关键帧，**逐轴插值**。
- 轴的含义：Z = 画面内旋转（就是旧的 2D 旋转），X = 俯仰，Y = 转身。计算顺序：先 Z，再 X，最后 Y（`R = Ry · Rx · Rz`）。只改 Z 时和现在的 2D 旋转完全一样。
- 旋转球保留，作为拖动工具，拖完写回三个值。
- 万向锁（X = ±90°）是已知限制。球面最短路径插值以后做成效果预设，这一版不做。
- **迁移**（打开项目时，只在内存里，保存时才写盘）：
  - **旧 2D 元素自动转成空间节点**。这一条改了"迁移只走显式脚本"的规则，已经用户批准；用 A 的 preserve 迁移器，画面逐像素一致；
  - `transform.rotation` → `rotation.z`；
  - `dir` + `roll` → 三个角。静止姿态完全不变；原来朝向的关键帧逐个换算，但插值从球面改成逐轴，帧间路径略有差别，列入报告；
  - 链接到 `roll` 的属性父级改成链接 `rotation.z`；链接到 `dir` 的无法直接对应，列入报告；
  - 相机：手动 roll → `rotation.z`，其余朝向见 §3。

## 3. 相机朝向 → 姿态预设（第三、四、五步）

- **相机原生只保留**：视场角（含鱼眼）、景深、运动模糊、相机栈的出画规则，以及和所有元素一样的位置和三轴旋转。
- **以下都变成效果预设，任何元素都能挂**：
  - **看向目标**：参数有对准轴（±X/±Y/±Z，相机默认 -Z）、上方向（世界向上 / 跟随目标 / 不约束）、目标（一个点，或者一个元素加目标自身坐标里的偏移）。只对准目标的位置，目标的旋转不影响。想让镜头跟着目标一起转，用空间父级。不做跟随平滑。
  - **沿路径朝向**：对准轴沿运动方向，可选转弯侧倾。
  - **抖动**：位置和/或旋转加随机噪声，有种子，结果可复现。
- **计算顺序**：自己的位置和旋转 → 空间父级 → 预设栈（按顺序，在世界坐标里算）→ 三轴旋转作为偏移叠加在预设之后。被预设接管的通道在界面上要标出来。
- 预设的目标也算进依赖关系，和空间父级、属性父级一起检查成环，成环就拒绝。
- **旧相机迁移**：自动挂上"沿路径朝向"（保留原来的看向点窗口）和"抖动"，画面不变。之后 `core/camera.js` 里的自动朝向逻辑才能删。
- 朝向方式要随时间切换的，**按片段**做（把相机在时间线上切开，后半段换预设），不做权重混合。

## 4. 新建相机

- 复刻**当前看到的画面**：编辑模式下复刻编辑视角；预览模式下复刻当前画面里最上层、实际看得见的那台相机。
- 只复制这一刻**算出来的最终机位**（一个静止关键帧，不带父级、不带预设），另外复制视场角和景深。
- 插在选中元素的上一层，没有选中就放最上层（和创建其它元素一样）。从播放头开始，持续 5 秒。
- 默认不挂任何朝向预设。

## 5. 运动路径推广到所有元素

- 以相机现有的贝塞尔路径和速度曲线为准，推广到所有元素的位置：都能显示运动路径、拖手柄、用整段速度曲线。
- **新建的运动关键帧**：没有缓动、匀速，轨迹是直线。
- **F4**：对选中的轨迹点切换"角点 / 平滑"。变成平滑时自动生成一对手柄，方向沿前后两点的连线，长度是相邻一段的 1/3；对平滑点再按 F4 就删掉手柄。
- 手柄关系：**对称**（默认）/ **对齐**（按住 Shift 拖，只改这一侧的长度）/ **断开**（按住 Alt 拖）。
- 三维拖动：默认在"过手柄、正对视角"的平面上拖；拖动中按 X/Y/Z 锁定世界轴，Shift+X/Y/Z 锁定垂直于该轴的平面；属性面板可以直接输入手柄偏移。
- 显示：轨迹点和手柄只在选中时显示；每个轨迹点向地面画一条竖线并标出落点；选中点显示坐标。
- 形状和快慢分开：贝塞尔只改形状，快慢由速度曲线（F2）管。
- **Ctrl+点击路径**：在路径上插入一个轨迹点。
- **旧项目**：没有手柄、靠自动平滑（Catmull-Rom）弯起来的路径，打开时写成真正的手柄，画面不变。
