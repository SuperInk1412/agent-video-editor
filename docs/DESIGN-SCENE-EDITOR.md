# 3D 场景编辑器 · 设计

> 目标：时间轴上的每一样东西，都是 3D 场景里的一个元素；元素的位置/旋转/缩放/透明度
> 都能打关键帧、都能配速度曲线；相机只是"会拍东西的元素"。
> Blender 与实时预览消费同一份烘焙数据，看到的 = 渲出来的。

## 0. 一句话

**场景是一棵树，时间轴是这棵树在时间上的展开。** 编辑模式像游戏旁观者一样在场景里走，
预览模式把画面绑在某个相机元素上；两者都能选中元素，选中状态在切换相机后保留。

## 1. 单位与坐标

- **全米制**。y 轴向上，右手系；地面 y=0。
- 旧 2D 项目迁移换算：`100 px = 1 m`（1920×1080 画幅 → 19.2×10.8 m）。
- 2D 项目 = 正交相机（`ortho_scale` = 画幅宽，米）；3D 项目 = 透视相机。同一个渲染器。
- 检查器可切换显示单位（m / px）作为便利，存盘只有米。

## 2. 元素模型

### 2.1 类型

| 类型 | 有几何 | 说明 |
| --- | --- | --- |
| `empty` | 否 | 空元素/骨头，只做变换，父子的主角 |
| `camera` | 否 | 会拍东西：预览、拍扁、成片都从它取画面 |
| `text` / `image` / `video` | 无厚度 | 平面贴图元素 |
| `solid` / `shape` | 有体积 | 盒子/圆柱等实体 |
| `audio` | 否 | 播放声音，时间维度上有入出点 |
| `container` | 否 | 合并产生的容器，见第 6 节 |

### 2.2 基础属性（全部可打关键帧 + 速度曲线）

| 属性 | 语义 | 单位 |
| --- | --- | --- |
| `pivot` | **中心点**在世界中的位置（旋转/手柄绕它） | m |
| `position` | 几何体相对中心点的偏移 | m |
| `scale` | 相对**自身几何中心**的缩放 | 倍数 |
| `rot` | 朝向 = 球面方向点 `dir` + 绕自身轴自转 `roll` | 单位向量 / ° |
| `opacity` | 整体不透明度 | 0–1 |

类型专属属性也进同一套关键帧：相机 `fov/near/far`、文字 `text/size/color`、图片 `fit`、
音频 `volume`、几何 `尺寸` 等。

### 2.3 变换

```
M = T(pivot) · R(dir, roll) · T(position) · S(scale) · G
```

- 旋转绕 `pivot`；`position ≠ 0` 时能做出"绕中心点公转"
- 缩放绕几何中心，与 `pivot` 无关
- 几何中心的世界位置 = `pivot + R · position`

### 2.4 旋转：球面上打关键帧

- 朝向存成单位球面上的方向点；关键帧 = 球面上的点
- 相邻点之间走**球面贝塞尔**：切线投影到切平面，评估后归一化
- 速度曲线作用在球面弧长上：路径形状与快慢解耦
- `roll` 是独立的标量通道，绕当前朝向自转（相机的荷兰角就是它）
- UI：检查器里的"旋转球"（拖方向点、关键帧点、切线手柄）+ 视口旋转手柄，写同一组通道

### 2.5 关键帧与速度曲线

每个通道是一条轨道：

```json
"tracks": {
  "pivot":   [{ "t": 0, "v": [0,150,-600], "ease": "easeInOut",
                "speed": [[0,0.2],[0.5,1.8],[1,1.0]] }],
  "dir":     [{ "t": 0, "v": [0,0,-1], "out": [0.1,0,0] }],
  "roll":    [{ "t": 0, "v": 0 }],
  "opacity": [{ "t": 0, "v": 1 }]
}
```

- `speed` 是**段级相对速度曲线**（`[u, v]` 点列，u/v 均归一化），先积分成弧长参数
  再取值，所以段末一定命中下一个关键帧
- 不写 `speed` 时退回 `ease` 预设（兼容旧数据）
- 位置类通道用 Catmull-Rom 穿过关键点（平滑），旋转通道用球面贝塞尔，标量通道线性
- 同一个通道的所有段共用一条通道轨道，可整体拖拽、框选、改插值

## 3. 空元素与父子

- `empty` 是纯变换元素，视口里显示为十字 locator
- 父子 = **按属性继承**：位置 / 旋转 / 缩放三个开关；绑定瞬间把相对偏移记下来
  - 摄像机挂到空元素下 → 转空元素 = 摇移/俯仰；空元素放场景某点 = 摇臂
  - 只勾"位置" = 跟着走但不跟着转
- 变换按矩阵组合：`childWorld = parentWorld · inherit(childLocal)`
- 框选两个元素 → 右键"绑定父子（B→A）"；大纲里也能拖
- 非变换属性的跟随（透明度/字号跟着谁）留作 v2 的 `links`

## 4. 时间轴

**时间轴只有元素这一种东西**，不同种类带不同属性。

- 每行 = 一个元素；行上切分它在时间维度上的存在：
  - 拖两端 = 裁入出点
  - `Ctrl+K` = 在播放头切开成两段
  - `Alt` 拖动 = 复制一段
- 展开属性子行（位置 / 旋转 / 缩放 / 不透明度 / 类型专属），关键帧菱形可拖、可框选、可改插值
- 类型徽标：相机（能拍）、音频（能出声）、实体（有体积）、平面/文字/图片（无厚度）、空元素
- **注释**独立在标尺上方一条细带：`[02.0–05.0] 这里起飞，镜头压低`
  - 给人看，也给 AI 看；不属于元素，不参与渲染
  - 原来的"分镜"迁移成注释

## 5. 模式与交互

### 5.1 编辑模式（旁观者）

- 自由相机：`WASD` 平移、`Q/E` 升降、`Shift` 加速、鼠标看向
- 视口内点击捕获鼠标；`Esc` 释放鼠标回到光标操作（选中/手柄/菜单）
- 网格独立开关

### 5.2 预览模式

- 画面绑定到指定相机元素（下拉切换）
- 与编辑模式一样可以选中元素；**切换相机后选中状态和高亮保留**
- 网格独立开关（和编辑模式各记各的）

### 5.3 环视模式（`Alt` 快速切换）

- 冻结移动，专注调画面：
  - **右键左右拖** = 画面滚转（歪头，不是摇头）
  - **左键前后拖** = 改变视场角
- `Esc` 或 `Alt` 退出，回到自由相机编辑模式 / 预览的相机编辑模式
- 编辑模式里只影响观察视角；预览模式里改的是相机元素的 `roll` / `fov`
  （自动关键帧开着就写帧）

### 5.4 选中（参照 Blender）

- 左键点选 / `Shift` 加选取消 / 空白处框选 / 点空白取消 / `A` 全选 / `Alt+A` 取消
- 大纲、时间轴、视口三向同步
- 右键始终是上下文菜单

## 6. 合并与拍扁 = 子场景

- 框选多个元素 → 右键"合并"：
  - **3D 一体**：生成 `container`，子元素以它为父，整体可变换
  - **拍扁**（选区里必须有相机）：容器内部是**独立场景**——自己的对象、自己的相机、
    默认**透明背景**；想要背景就在里面加元素
- 容器在父场景里是一块"屏幕"（相机画面），可以继续移动/旋转/打关键帧
- 双击进入：时间轴切到子场景、预览切到内部；面包屑退出
- 预览作用域与时间轴作用域解耦：时间轴在内部、预览看总体，随时对照
- 容器可再合并拍扁（嵌套限深度 + 防环）

## 7. 渲染、烘焙与一致性

- 一个场景渲染器：正交/透视、深度、贴图对象、透明排序、子场景 FBO
- **烘焙场景包**：逐帧输出每个元素的 `pivot/position/rot/scale/opacity` + 类型属性 + 相机
  - Blender 只负责摆，不再复刻求值逻辑
  - 预览与成片同源
- 拍扁容器：预览离屏渲成贴图并缓存（子树哈希 + 相机 + 分辨率 + 时间）；
  Blender 先渲子场景每帧 PNG（带 alpha），主场景当图像序列贴图
- 编辑时用低分辨率代理，出片用全分辨率
- 后期链（bloom/grade/grain…）作用在最终画面上

## 8. 迁移

- `elements[]` → 元素；像素 ×0.01 → 米；`z` 层级 → `pivot.z`
- `segments[]` → 注释（保留名称/意图/状态）
- `camera` → 相机元素；`camera.path` → `pivot` 轨道；`lookAhead` 先转 `dir` 关键帧
- 旧项目渲染结果必须逐像素不变（golden 帧比对），对不上不合并

## 9. AI / CLI

- 所有编辑都走 ops；AI 不需要鼠标：
  - `vdm obj add text "夜之城" --at 2 --pos 0,18,-40 --size 6`
  - `vdm obj key el_title pivot --t 2 --value 0,18,-40 --ease easeOut`
  - `vdm obj bind cam1 empty1 --pos --rot`
  - `vdm scene flatten --ids a,b,cam1`
  - `vdm scene lint --json`（出画、穿模、关键帧空洞、速度尖峰、父子环）
- AI 闭环：写参数 → lint → 看起/中/末三帧 → 修
