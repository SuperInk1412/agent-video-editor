## 0. 一句话

F2 曲线面板 = **选区（池级、跨属性、跨元素）的曲线编辑器**：选中的关键帧是锚点，
段内未选中的键按曲线重定时，整条属性轨连续显示，Tab 在选中属性之间轮换，
关键帧和手柄都能直接拖。

---

## 1. 术语

| 词 | 含义 |
|---|---|
| 池 / 选区 | 时间轴当前的关键帧选中池 `S.selection.pool`（`el:` / `ob:` / `cam:` 混合） |
| 组 | 按 `(host, path)` 分组的选中键；只有组内 ≥2 键才会成段 |
| 段（span） | 同一组里**相邻的两个选中键**之间的范围；段内可能有未选中的键 |
| 子段 | 段内相邻键对（含内键），每个子段左键各存一条曲线 |
| 锚点 | 被选中的关键帧：时间、值都不动 |
| 内键 | 段内未被选中的关键帧：值不动，时间由曲线决定 |
| 进度 | 插值参数 0..1；标量轨里是值归一化位置（颜色轨没有进度，见 §5） |

---

## 2. 三种轨

| 轨 | y 轴 | 说明 |
|---|---|---|
| 标量属性（中心点/缩放/旋转各轴、不透明度/字号/FOV/相机参数…） | **真实数值** | 整条轨连续画出 |
| 颜色（`style.color` / `style.fill`） | **[R2] 无刻度（阶跃色带）** | **[R2]** 每个键在 `[键, 下一个键)` 区间保持自己的颜色：横向色带 + 键处竖直跳变；没有手柄和预设，只能改时间 |
| **[R1] 运动路径**：所有元素的位置（相机飞行轨迹不在本次范围，见文首注） | 进度 + 速度曲线 | 位置按整个轨迹点打键（变换统一 §5、§9），贝塞尔只管形状、快慢由这里管；**进 Tab 循环**，但不和数值轴混画 |

**[R1] 多轴属性**：中心点 / 旋转 / 缩放按变换栏的「总行 + X/Y/Z 子行」组织（变换统一 §9）。
选中总行 = 三条轴曲线叠画在同一视图（X 红 / Y 绿 / Z 蓝，可单独隐藏某一轴）；选中子行 = 只看这一轴。

## 3. 选区与作用域

- 分组：按 `(host, path)`；组内 **≥2 个选中键** → 相邻选中键两两成段。
- 点预设 = **整个池子**一起应用，跨属性、跨元素；不足 2 键的组跳过；**[R2] 颜色组跳过（不写 curve、不计入 toast）**。
- **[R1] 修饰键**：**Shift+点预设 = 只应用当前显示的属性**（总行 = 它的三个轴）；
  **Alt+点预设 = 只写曲线，不挪内键**（不重定时）。两者可同时按。
- **[R1] 悬停预览**：鼠标停在预设上时，当前行画出新曲线的虚影，内键画出"将移到哪里"的残影；
  表头列出会受影响的范围（如「旋转 X / 旋转 Y / 不透明度 · 3 个元素」）。移开即消失，不写数据。
- 全池都不足 2 → toast「再添加一个关键帧」，不动数据。
- 成功 → toast「已应用到 N 条属性 · M 段 · K 个内键已移动」**[R1]**。
- 只选 1 个键：面板可以打开、可以看曲线，点预设只 toast。
- 面板一次只显示一行：默认时间轴**最上面**的选中属性行。
- **Tab**：在选中属性行之间按时间轴行序循环（含折叠/被过滤的 host），末行回首行；
  Shift+Tab 反向；只在面板打开且焦点不在输入框/下拉时生效。
  **[R1]** 多轴属性按**属性**跳（总行算一行），不按轴跳；子行单独被选中时才作为一行。
- 没有"当前段"概念：手柄直接画在所有可编辑段上，不再有 active 段索引。

## 4. 数值语义（标量轨）

```
A(选中) … B(未选中) … C(选中)        y_B = (v_B − v_A) / (v_C − v_A)
t_B = t_A + firstArrival(curve, y_B) · (t_C − t_A)     // 单调、毫秒取整
```

| 规则 | 结果 |
|---|---|
| A、C（锚点） | 时间、值都不变 |
| B 的值 | 不变（越界例外见下） |
| B 的时间 | 搬到曲线第一次到达 `y_B` 的位置（与相机 `retimePathSpan` 同规则） |
| 段内每个子段左键 | 写入同一条曲线 → 分段线、形状同步 |
| 段外的子段 | 保留原有曲线 |
| `ease` 字段 | 原样保留，只写 `curve` |
| `v_A == v_C` | 跳过重定时，仍写曲线 |
| 越界（`y_B ∉ [0,1]`） | **每次应用都重新检查**：越界时以时间为锚（时间不动，把 B 的值改到曲线上当前时间的值）；此后在曲线上、按值重定时 |
| 回弹/弹性 | 每个子段各回弹一次 |
| 抖动/步进类 | 同现有 `curves.js` 语义，不做特殊处理 |

时间约束：内键时间严格递增、夹在 `(t_A, t_C)` 内、毫秒取整（沿用
`retimePathSpan` 的 `+0.0005 / −0.0005` 与 `last + 0.001` 保护）。

**[R1] 多轴一起重定时**：同一宿主的同一属性（如 `rotation.x/y/z`），若几条轴在**同一时刻**都有内键，
这一组内键合成**一个**进度、搬到同一个新时间，不各算各的——否则同一时刻的姿态会被拆散。
合并办法：每条轴按上面的公式各自算出进度 `y_i`，取算术平均（即 `y_i` 的最小二乘解）并夹到 [0,1]；
`v_A == v_C`（该轴没跨度）的轴没有进度，不参与平均。只有单轴有键的时刻照常单轴计算。
（**[R2]** 这里借的只是"多轴合成一个进度"的算法，与颜色无关——颜色不插值，见 §5。）

**[R1] 越界提醒**：回弹/弹性等预设可能让值超出属性上下限（不透明度 > 1、缩放 < 0 等）。
曲线超出的部分画成红色；应用时 toast 补一句「部分值超出范围，成片会截断」。

## 5. 颜色（RGB 三通道，保持跳变）

- **[R2] 定案（用户 2026-10-28）**：颜色**保持跳变**，不引入插值。现在 `core/time.js::sampleTrack`
  对非数值返回左键的值；改完后行为一模一样，所以**没有求值语义变更**：`core/time.js`、
  `core/evaluate.js`、`blender/vdm_build.py` 一行不动，不需要迁移，也不需要颜色对拍。
  R1 §5 原先"旧键写显式步进曲线、新键默认渐变"的方案作废——`curves.js` 的
  `{type:'step',params:{stepLength:1,smoothing:0}}` 确实能精确表达阶跃，但为了"画面不变"
  去改写用户项目里已有的键，代价不值。
- 现状核对：miku-swiss 有 19 个元素、37 个 `style.color` 键，方案取消后这些键**零改动**。
- **面板显示**（y 轴不画刻度、不画值标签）：
  - 每个键在 `[键, 下一个键)` 区间**恒定**显示它自己的颜色：一段横向色带，键的位置一条竖直跳变线；
  - 色带用真实颜色（不打亮度折扣、没有渐变）；浅色色带上加一圈细边框保证可见；
  - 第一个键之前、最后一个键之后按该键颜色水平延伸到轨两端；
  - 键上残留的 `curve`/`ease` 字段不显示、也不清理（求值不看它们，留着无害）。
- **颜色键只能左右拖（改时间）**：整帧吸附、Alt 临时自由，与标量轨一致。
- **颜色轨没有手柄、没有预设**：颜色组整组跳过"点预设"（toast 里的属性数/段数都不计它），
  也不出控制点（§7）；颜色值本身在属性面板改（§9）。
- 选区 / 框选 / 加选 / ←→ 微调与标量轨完全一致（§8），颜色键照样能精确摆位。
- **[R1]** 双击颜色键：播放头跳到这个键，并聚焦属性面板的颜色行（展开选色面板），不再"没反应"。

## 6. 面板显示

- x 轴 = 时间轴绝对轴（gutter / pps / scroll 完全一致）；滚动、缩放、播放头同步。
- 标量轨：整条轨连续绘制；第一个键之前、最后一个键之后按真实值水平延伸；
  y 轴自适应整轨范围并给预设 overshoot 留白；单位/步长取时间轴属性行的元数据。
- Tab 切换行时 y 轴做约 150ms 过渡。
- 选中段：高亮底色 + 加粗；选中的键有明确选中态；未选中的内键随重定时移动。
- **F2 打开**：先暂停播放；把选中范围滚进时间轴视野，**不改缩放**。
- **播放头**：打开 / Tab / 属性下拉切换时，若播放头不在当前显示属性的选中范围内，
  跳到该属性**最靠前的选中键**；这次跳转不再额外滚动时间轴。
- 标题/表头：显示当前 host + 属性、池子摘要（N 键 · M 条属性 · K 个对象）。
- **[R1] 归一化开关**：叠画多条曲线（三轴，或以后同屏多属性）时，单位/量级不同放不进同一 y 轴；
  打开后每条曲线各自缩放到 0..1 显示（只影响显示，拖动仍写真实值）。
- **[R1] 内键标记**：重定时后不在整帧上的内键画成空心；见 §8「对齐到帧」。
- **[R2] 颜色轨按 §5 画阶跃色带**：y 轴不画刻度和值标签，色带占满整条轨的高度。

## 7. 手柄

- **[R1] 出现条件 = 段被选中**（两端都选中），不再要求先套预设。
  - 左键已有 `curve` → 按存储的曲线出柄；
  - 没有 `curve` → 把当前 `ease` 拟合成一对手柄（16 点最小二乘；线性 = 手柄落在直线上）。
    `outExpo` / `outBack` 这类没有精确的三次贝塞尔等价，拟合误差只影响"还没拖"的预览；**一拖就生成 `curve`**；
  - 含未选中内键的段同样出柄；拖动时内键按 §4 实时重定时（Alt 拖 = 不重定时）；
  - 取消选中任一端 → 该段手柄消失、退出同步。
  - 与变换统一 §5 运动路径的 F4（默认直线、按需出柄）手感一致。
- **池级同步**：拖任一手柄，所有被选中的可编辑段写入同一条曲线（同一组控制点/参数）。
- **[R2] 颜色轨不出现手柄**：颜色组整个跳过手柄与池级同步（没有可插值的形状）。
- 拖动中实时重定时内键并重绘整条轨；松手一次 op；Esc 恢复。
- 数值区间为 0 的段（`v_A == v_C`）仍可拖手柄改形状，只是不触发重定时。

## 8. 交互

| 操作 | 行为 |
|---|---|
| 点击键 | 替换选择 |
| Ctrl/Cmd/Shift + 点击键 | 加减选 |
| 框选 | **替换整个池子**（与时间轴一致）；Ctrl/Shift 框选为加减选 |
| 点空白 | **[R1] 不改选区**（选区是在时间轴上跨元素挑的，误点代价太大） |
| Esc | 取消当前框选/拖动并恢复；**[R1] 没有进行中的操作时，再按一次 Esc 清空池子**；清空可 Ctrl+Z 撤回 |
| **[R1]** ← / → | 选中键按帧左右移（Shift = 10 帧） |
| **[R1]** ↑ / ↓ | 选中键（标量）按属性行 step 改值（Shift = ×10）；颜色键无效 |
| **[R1]** Ctrl+C / Ctrl+V | 复制所在段的曲线；粘贴 = 把这条曲线应用到当前池子（同点预设，含 Shift/Alt 修饰） |
| **[R1]** 右键段 | 「存为我的预设」（进预设列表的"我的"分组）、「反转曲线」（缓入 ↔ 缓出，左右镜像）、「对齐到帧」 |
| **[R1]** 对齐到帧 | 把池子里不在整帧上的内键移到最近的整帧（保持严格递增），一次 op |
| **[R1]** 双击颜色键 | 跳播放头 + 聚焦属性面板颜色行（§5） |
| 键左右拖 | 改时间：整帧吸附，Alt 临时自由；**保留 curve** |
| 键上下拖（标量） | 改值：按属性行 step / 单位 / 上下限 |
| 键上下拖（颜色） | 无效（颜色只能在属性面板改） |
| 拖未选中的键 | 先自动选中它（成为锚点，段分裂），再拖 |
| 拖锚点 | 相邻段的内键实时重定时 |
| 拖手柄 | 池级同步；实时重定时；松手一次 op |
| 点预设 | 池级应用 + toast；失败回滚并提示；**[R2] 颜色组跳过（不写 curve、不计入 toast 数字）** |

一次手势 = 一个原子 op；Ctrl+Z 一步撤回。

## 9. 属性面板的颜色控件

复用 X/Y/Z 行的排版，新增一行：

```
颜色   [▸]  [▓▓]   R [255]  G [ 59]  B [107]   [◆]
       展开  色块    ← 0–255 数字框，复用 xyz 数字框的拖动/输入行为
```

- 左侧 `▸` 展开内联选色面板：大色块预览、十六进制输入、"取色…"（系统颜色选择器）、
  最近使用的颜色；色块带边框，作为展开/取色按钮。
- `◆` 与其它行一致：有键时改播放头所在的关键帧，没键时改基础值；点 ◆ 打帧/删帧。
- 实时预览：拖动/输入 RGB 立即反映到预览与色带，松手/失焦提交一次 op。
- 只给可打帧的颜色加 ◆：文字 `style.color`、色块 `style.fill`、3D 文字颜色；
  世界背景/项目背景沿用简单色块，不加关键帧。
- 曲线面板里改颜色键的颜色：**不支持**，统一在这里改。

## 10. 数据与 op

- 一次手势 = 一个 `batch`：每个子段一条 `keyCurve` + 内键移动 + （越界时）内键改值。
- **前置修复**：现在时间轴搬键用 `keyRemove + keySet`，`keySet` 只在"新时间已有关键帧"
  时继承 `curve` → **搬一个带曲线的键会丢曲线**（面板的拖键同样会中招）。
  修法：给 `keySet` / `objectKey` / `cameraParamKey` **[R1 改名]** 增加 `curve`/`spanTo` 透传，或新增
  `keyMove` op 直接搬键对象。时间轴的拖键一并受益。
- **[R1]** 若新增 `keyMove`：旧写法路径（`transform.*`、`roll`、物体 `dir`）要在 `core/rotation-ops.js`
  的翻译里加上 `keyMove`（B 负责，A 加 op 时告诉 B）。
- **[R1]** 自定义预设存放：项目级 `meta.curvePresets[]`（名字 + 曲线），随项目走；不写全局配置。
- **[R1]** 以后姿态预设（变换统一 §3）的可打帧参数也是普通标量轨，自动进曲线面板，无需特殊处理。
- 新增重定时所需的搬键能力（毫秒级，非整帧）；锚点拖动走整帧。
- **[R2] 颜色轨只有两类 op**：搬键（改时间）与属性面板的打帧/删帧；不写 `curve`、不搬内键，无 schema 变更。

## 15. 附录 A：已作废的颜色插值方案（备查，2026-10-28 R2 作废）

> 保留 R1 §5 原方案，供以后想做"颜色过渡"时直接捡起来。**现在不执行**。

- **为什么当初想做**：颜色关键帧现在是硬跳变（`sampleTrack` 对非数值返回左键的值）；
  渐变能让文字/色块的换色有过渡，且不需新增字段（RGB 就在字符串里）。
- **求值**：每个子段按同一进度逐通道 lerp，`c(t) = lerp(c_A, c_B, curve(p))`；
  没有 `curve` 时用 `ease`。要改三处并保证数值一致：
  `core/time.js::sampleTrack`（唯一的 curve 逻辑，`core/evaluate.js` 调用它，**不用单独改**）、
  `blender/vdm_build.py::sample_track`。颜色值是 `#RRGGBB`（现存值有大小写混排，写回时统一大小写即可）。
- **旧项目"画面不变"的迁移办法（已验证可行）**：打开项目时给每个已有颜色键写一条显式阶跃曲线
  `{ type:'step', params:{ stepLength:1, smoothing:0 } }`——`stepSample` 在 u∈[0,1) 上恒返回 0，
  所以 lerp 结果恒等于 `c_A`，与现在的 step 行为逐帧相同。
  迁移要**先判空**：`progress <= 0` 直接返回 `a.value` 字符串，避免 hex 往返改大小写。
- **面板**（y = 混色进度 0..1）：段内画竖向渐变（底 = 左键色、顶 = 右键色，压暗 50% 便于看清曲线），
  曲线从段左下爬到段右上，颜色键画在左下/右上角，内键画在 (t, 进度)。
- **内键重定时**：把内键颜色投影到段两端 RGB 连线上（逐通道最小二乘系数，夹 [0,1]），
  落在插值线上的颜色其系数等于逐通道进度；两端同色时跳过重定时、仍写曲线。
- **风险**：所有旧项目的颜色渲染都会变（画面可见变更）；迁移要在打开项目时写数据；
  三处求值必须对拍（RGB 完全一致）。

## 17. P2 实现约定（开工后补充，2026-10-28）

空隙分析（`curvepanel.js` 1491 行逐行核对）发现几处设计稿没写死的接缝，按以下方式落地：

- **搬键的 op**：不新增 `keyMove`。一次搬键 = `keyRemove`/`objectUnkey`/`cameraParamUnkey` + 对应的
  `keySet`/`objectKey`/`cameraParamKey`，后者带 `curve`（`bbd328f` 已支持显式透传，`null` 清除）；
  搬键 + 写曲线的一次合并由 `core/curve-spans.js::spanCurveOps()` 生成，多轴传 `tracks[]`。
  整段套预设 / 拖锚点 / 对齐到帧都走它，一个 `batch` = 一次撤销。
- **快捷键优先级**：Tab、←/→、↑/↓、Esc 已被全局命令占用（`main.js` 的 `toggleEdit`、逐帧步进、
  关面板）。面板在**捕获阶段**监听 keydown，命中且焦点不在输入框/下拉时 `stopPropagation`；
  面板关闭时不拦截，全局行为不变。
- **Esc 三段式**：拖动中 → 取消拖动并恢复；否则池子非空 → 清空池子（可 Ctrl+Z 撤回）；
  池子已空 → 关面板（交给原有的关闭逻辑）。
- **选区不是快照**：面板开着时时间轴改选，`main.js` 的 `select()` 回调把新池子推给
  `curvePanel.setSelection()`；池子变化后重算段与手柄，不重开面板、不改缩放。
- **行元数据**：`curveTracksFor()` 顺带带上 `unit` / `step` / `min` / `max` / `rowOrder`
  （常量表取，**不抓 DOM**），因为 `timeline.js` 正在改行结构。
- **无 `curve` 的段**：手柄形状用 `core/curve-spans.js::curveFromEase(ease)` 拟合（16 点最小二乘，
  线性/缓入/缓出精确，`outExpo` 误差约 0.08），不再假装 `easeInOut`；一拖就写真实 `curve`。
- **内键空心**：帧率从 `timeline` 取；`|t* fps − round(t* fps)| > 1e-3` 视为不在整帧上。
- **y 轴过渡**：缓存上一段区间，切换行时 150ms 逐帧插值（只影响显示）。
