# VedioMaker UI 设计规范

> 渲染器（`app/renderer/`）的唯一 UI 规范。做任何可见改动前先读这里；规范与代码冲突时，
> 先改规范再改代码。求值/渲染语义不在本文范围，见 `SPEC-PROJECT.md`。

---

## 0. 原则

1. **画面优先。** 预览是主角：外壳用低饱和的蓝灰，只有「选中 / 激活 / 播放头 / 关键帧」有颜色。
2. **一事一个主入口。** 每个动作只有一个固定位置的主按钮；快捷键、右键菜单、命令面板是它的快捷方式，
   文案和图标与主入口一致。不在两个面板各放一套同样的按钮。
3. **可发现。** 每个按钮都有提示（`data-tip`），有快捷键的在提示里显示 `kbd`；所有动作都能在
   命令面板（Ctrl+K）里搜到；快捷键速查表（`?`）列全部按键。界面上不再铺长段快捷键说明文字。
4. **紧凑但不挤。** 4px 网格，控件 22–30px 高，最小字号 11px。能横排就不竖排（标签和输入同一行）。
5. **状态始终可见。** 选中了什么、当前是否在关键帧、引擎/Blender/AI 是否可用、渲染进度，都有固定位置显示，
   不依赖一闪而过的 toast。
6. **颜色即语义。** 颜色只表达含义（见 §3.2），不用来装饰；不用渐变、霓虹辉光做外壳装饰
   （画面内容与选中描边除外）。

## 1. 布局

```
┌ 顶栏 40 ───────────────────────────────────────────────────────────────┐
│ ◆ 项目▾  ↶ ↷ │      选择 相机 文字 色块 3D▾      │ 编辑视口|镜头  ⌘K  预览帧  渲染成片▾ │
├────────────┬┬──────────────────────────────────────┬┬──────────────────┤
│ 左栏        ││ 舞台工具条 32                         ││ 右栏              │
│ 资源 | 图层  ││ ┌──────────────────────────────────┐ ││ 属性 | AI | 渲染   │
│            ││ │           预览画布（等比居中）        │ ││                  │
│ 260 (200–420)│ └──────────────────────────────────┘ ││ 340 (280–520)     │
│            ││ 播放条 40                              ││                  │
├────────────┴┴──────────────────────────────────────┴┴──────────────────┤ ← 可拖
│ 时间轴工具条 32                                                         │
│ 时间轴（默认 280，160 – 视口高 60%）                                     │
├────────────────────────────────────────────────────────────────────────┤
│ 状态栏 24                                                               │
└────────────────────────────────────────────────────────────────────────┘
```

- `#app` 是 CSS grid：`grid-template-rows: 40px minmax(0,1fr) var(--tl-h) 24px`；
  `main` 是 `var(--left-w) 4px minmax(480px,1fr) 4px var(--right-w)`。尺寸只来自这三个变量。
- **分隔条（splitter）**：命中区 4px，静止时画 1px `--border`，悬停/拖动时画 2px `--accent`，光标
  `col-resize` / `row-resize`。双击分隔条折叠/展开相邻侧栏（时间轴分隔条双击 = 恢复默认高度）。
  侧栏折叠后宽度为 0，在对应边缘留一个 16px 的展开把手（`›` / `‹`）。
- 窗口最小 1100×700（Electron 已限定）。宽度 < 1440 时顶栏工具按钮只显示图标（文字进提示）。
- **持久化**：`localStorage['vdm.ui.v1']` 存 `{ leftW, rightW, tlH, leftCollapsed, rightCollapsed,
  leftTab, rightTab, sections:{}, loop, safeArea, snap, tlGutter }`。读写一律 `try/catch`，读不到就用默认值；
  这里只放界面偏好，永远不放项目数据。

### 1.1 顶栏（40px）

| 区 | 内容 | 说明 |
|---|---|---|
| 左 | logo ◆ · **项目按钮**（标题 + ▾） · 撤销 · 重做 | 项目按钮下拉：打开项目… `Ctrl+O`、新建项目…、打开文件夹…、分隔、重启引擎 `Ctrl+Shift+R`。项目元信息（分辨率/fps/时长/rev）移到状态栏，悬停项目按钮也显示 |
| 中 | 工具组：选择 `V` · 相机（新建，当前视口机位） · 文字 · 色块 · 3D ▾ `Shift+A` | 选择是切换态（`.on`）；其余是「添加」动作。3D ▾ 菜单分组：3D 物体（立方体/圆柱/钢笔）、场景元素（空元素/图片…/视频…/3D 文字） |
| 右 | 视图分段控件 [编辑视口 \| 镜头视角] `Tab` · 命令 `Ctrl+K` · 预览帧 · **渲染成片 ▾**（分裂按钮） | 渲染成片是全界面**唯一**的 primary 按钮。▾ 菜单：分辨率 50% / 100%（单选，替代原顶栏 select）、渲染当前段、取消渲染（仅渲染中可用） |

### 1.2 舞台（中栏）

- **舞台工具条（32px）**，在画布上方：
  - 左：视图状态。镜头视角时显示 `镜头视角` 徽标；编辑视口时显示分段控件 [选择 \| 移动]（`Alt` 切换），
    移动态用 `--edit` 琥珀色。
  - 中：`网格`（`G`，只在编辑视口有效，镜头视角时呈弱化但仍可点并提示）· `安全框`（新增，叠加 90% 字幕安全框、
    93% 动作安全框和中心十字，仅 UI 叠加层，不进成片）。跟随相机时这里显示 `跟随 <相机名> ×`，
    点一下脱离跟随，视角留在当前机位。
  - 右：`1920×1080 · 30fps`（弱化文字）。
- **画布**：等比适配、居中、外圈 1px `--border`；编辑视口时外圈换成 2px `--edit` 描边（现有 look-mode 语义）。
  画布四周留 12px。删除画布下方那条长快捷键提示。
- **播放条（40px）**，在画布下方：
  `⏮ 首帧(Home)` `◀ 上一帧(←)` **`▶/⏸ 播放(Space)`** `▶ 下一帧(→)` `⏭ 末帧(End)` `循环(L)` ·
  **时间码** · `/ 总长` · 右侧：当前选中摘要（类型徽标 + 名称）· `?` 快捷键速查。
  - 时间码：等宽数字，格式 `00:01.80` + 弱化的 `f54`。点击变为输入框，接受 `1.8`、`1:02.5`、`54f`/`f54`
    （帧号），Enter 跳转，Esc 放弃，非法输入时输入框描边变 `--danger` 并保持编辑。
  - 循环：开启时播放到结尾回到 0 继续；状态持久化。

### 1.3 左栏：资源 | 图层

**资源（媒体库）**
- 头部：搜索框（按文件名过滤，即时）+ `导入`（图标按钮，打开文件选择）。
- 类型筛选分段：全部 · 视频 · 图片 · 音频，各带计数。
- 卡片网格：`repeat(auto-fill, minmax(104px, 1fr))`，16:9 缩略区 + 一行名称（省略号）。
  左上角类型徽标；配乐卡片带 `配乐` 徽标并用 `--accent` 描边。
- 交互：单击 = 选中卡片（高亮，状态只在面板内）；**双击或悬停出现的 `+` = 在播放头加入**；
  **拖到时间轴 = 按落点加入**：拖动时轨道上显示跟随鼠标的半透明 ghost，ghost 左边缘就是新元素起点，
  松手按 ghost 起点创建；右键菜单：在播放头加入、设为配乐（音频）。
- 已用过的素材：缩略图/名称轻微变暗并显示「已用」提醒，**仍可再次添加/拖动**（不是禁用）；
  删除或撤销后自动恢复。资源面板新增的素材：图片 5s；视频/声音按源时长（未知回退 5s）；
  项目时长不足时自动延长，并保持当前缩放/滚动；素材行位置仍遵 §1.5 的新元素规则。
- 把系统文件拖进面板 = 上传（面板出现虚线高亮的放置层，文案「松开导入」）。
- 空状态：图标 + 「导入素材」+「把视频、图片或音频拖到这里，或点导入」+ `导入` 按钮。

**图层（大纲）**
- 头部搜索框（按名称/id 过滤）。分组可折叠：相机 · 3D 元素 · 2D 元素 · 声音，组头带计数。
- 行 24px：类型图标 · 名称（省略号） · 右侧等宽弱化时间范围 `0.00–1.68`。
  当前时间不在其时间范围内的行，名称用 `--text-3`。
- 单击 = 选中（走与时间轴/舞台相同的 `select()`）并让时间轴滚动到该行；双击 = 跳到其起点。
  选中行：`--accent-bg` 底 + 左侧 2px `--accent` 条（直角，无圆角）。

### 1.4 右栏：属性 | AI | 渲染

日志从右栏移到状态栏的日志抽屉（§1.6）。原「流水线」页改名为「渲染」。

**属性面板**
- 粘性头部：类型徽标 · 名称（单击可改名）· 弱化 id · 右侧图标按钮（复制、删除 `danger`）。
- 分组（section）可折叠：组头 28px，`▾/▸` + 标题 + 右侧可选的组级操作；折叠状态按「对象类型 + 组名」持久化。
- **属性行**：10 列网格 `72px repeat(6,minmax(0,1fr)) 18px 20px` —— 标签 | 控件（按需 2/3/6 列） | ↳ | ◆。
  控件按类型和内容长度取 **1/3、1/2 或整行**：短数值 1/3，中等值 1/2，长文本/路径/下拉/文本域/向量/
  只读行整行，颜色 1/2。宽度由静态字符预算（step / 边界 / 单位 / 当前值）一次决定，不在输入时测量；
  ◆ 固定在最右列，不随字段宽度移动。
  - 向量属性一行内放 2–3 个数值框，每个框带彩色轴字母前缀（X 红 / Y 绿 / Z 蓝）。
  - 单位写在数值框内的后缀（`s` `px` `°` `%` `m`），不写在标签里。
  - ◆ 三态：无动画 `◇`（`--text-3`）；有动画但当前不在关键帧 `◇`（`--keyframe`）；当前帧有关键帧 `◆`
    （实心 `--keyframe`）。单击在播放头打帧，Shift+单击删除当前帧的关键帧（现有语义）。
  - 颜色属性：色块（24×24）+ hex 文本框。下拉框、文本域占满控件列。
- 时间轴「变换」栏与属性面板同构：中心点 → 位置 → 旋转 → 缩放（+ 不透明度），一行三格、行首一个总 ◆；
  行首 `▸` 展开 X/Y/Z 子行逐轴打帧，收起时父轨道合并显示。相机旋转在变换栏内，画面中心/位置在
  「镜头 / 构图」；2D 平面缩放 Z 变灰；相机位置只读（飞行路径）。
- 无选中时显示项目/镜头/世界设置（现有 `_renderProject` / `_renderCamera` 的内容，套用同一套属性行）。

**AI**
- 头部：状态点 + `AI 副驾` + 状态文字（就绪 / 运行中… / 未找到 DSH-TUI）。
- 中部消息流（占满剩余高度，自动滚到底）：你的任务（`--surface-2` 卡片）、AI 回复（正文）、
  思考（弱化斜体，默认折叠成一行「思考中…」）、工具/操作（等宽小字卡片，如「应用 3 个操作」）、错误（`--danger`）。
- 底部输入区固定：上下文开关（当前分镜 / 选中元素 / 截 3 帧给 AI 看）→ 自增高文本框（3–8 行）→
  `发送`（`Ctrl+Enter`，运行中变为 `停止`，`danger`）。
- 空状态：3 条示例任务做成可点的建议，点击填入输入框。

**渲染**
- ① 渲染任务卡：进度条 + `帧 12 / 450` + 状态；按钮：预览帧（当前时刻）、渲染当前段、渲染成片、
  取消（仅渲染中显示）。分辨率分段 50% / 100%，与顶栏菜单是**同一个状态**。
  这一页的按钮都用默认样式（primary 只在顶栏）。
- ② 流水线步骤（分镜 → 预览帧 → 片段 → 成片），竖向紧凑步骤条，状态色见 §3.2。
- ③ 自动分镜（可折叠）：风格、分镜文案、生成分镜、分析节拍。
- ④ 产出：缩略图网格，图片可点开，视频/文件显示图标。

### 1.5 时间轴

- **工具条（32px）**：左 筛选框（按名称过滤行，显示 `n / 总数`，`Ctrl+F` 聚焦）· `仅带键`（`U`）·
  `吸附`（磁铁，开启时吸附到 0/结尾/节拍，持久化；拖动时按住 Alt 临时关闭，沿用现有行为）· 分隔 · `切开`（`Ctrl+D`）·
  `曲线`（`F2`）；右 缩小 · 缩放滑杆（对数刻度）· 放大 · 百分比 · `适应`（= 双击标尺）。
- **仅带键（U）**：对当前元素池（2D / 3D / 相机混选）生效：只展开带键 host 的属性行，并隐藏组标题行；
  无键 host 保持单行。第二次 U 恢复按 U 之前的展开、分组和滚动位置。池为空或没有带键 host 时不改变画面。
- 删除底部提示条（`.tl-hint`），缩放控件移到工具条。
- 行高：属性行 28px，元素/相机/3D/声音头行 30px（左侧名称栏是一条统一列表，不再按类型分组）。
  名称栏宽 `--tl-gutter`（默认 340，280–480，拖名称栏右边界调整，持久化）。
- **统一图层列表与拖动排序**：名称栏把 相机 / 2D / 3D / 声音 行放进同一条列表，行头可上下拖动；
  拖动时显示插入线、被拖行变淡、靠边自动滚动，Ctrl 多选可整组移动。行间顺序保存在
  `meta.ui.timelineOrder`（`cam:/el:/ob:`），只有 2D 行的相对顺序写回 `el.z`、相机行的相对顺序写回
  `cameraOrder`；3D 与声音行只改显示，不影响画面。一次拖动 = 一次撤销；筛选框有内容时暂不拖动。
  行头按钮顺序统一为 **眼睛 | 空间父级 | 折叠 | 类型点 | 名称**（相机、2D、3D 一致）。
  相机行名称后另有只读的「被投屏 ×N」提示（只统计可见的投屏元素，隐藏相机照样能被投屏）；
  它不再控制相机是否出画。
- **空间父级**：从行头的父级按钮按住拖到另一行，出现连线，目标行高亮；松手绑定，连线闪一下消失，
  子级行按钮常亮。点击亮起的按钮解除。子级支持 2D 元素 / 3D 物体 / 相机，父级也可以是其中任意一类；
  屏锁（`@live` / 旧相机贴屏）不是空间父级，也不能当空间父级的目标。属性面板首行显示
  「空间父级：名称」+ 转到父级 / 解除。3D 物体原有的「父级」区仍是旧层级图（`obj.parent`），
  与空间父级（`obj.frameParent`）并存，不互相删除。
  **已知 gap**：相机作为子级时，预览/Blender 的取景会跟着父级，但相机路径 gizmo 的关键点仍按
  本地相机坐标显示和拖动（路径动画本身不变）。
- **属性父级**：属性行左列的 `↳` 打开同单位来源菜单（长度 / 角度 / 比例 / 数值各自成组；
  相机 `position.*` 是路径动画，不作为来源）。有链接时按钮亮起，右键也打开同一菜单；
  菜单里的「转到父级」会展开父级 host、滚到对应属性行并选中。跳转后属性面板顶部出现「← 返回」，
  与 `Alt+←` 一起恢复跳转前的选中、展开和滚动位置；Ctrl+Z 始终只做全局撤销。
  环和过深链路由 core 拒绝并 toast。2D / 3D / 相机的时间轴属性行都显示有效值（旁边有「父」标记），
  编辑时反写本地值；同一个有效值也用于预览、shot 烘焙和 Blender 成片（`core/link-eval.js`），
  属性行与画面不再有「只改显示」的差异。已迁移 `el.node` 元素的属性面板和时间轴都使用
  **中心点 / 位置 / 三轴旋转 X/Y/Z / xyz 缩放**（时间轴按轴拆成单行，保留现有菱形和拖动机制）。
  属性面板的「空间父级：…」摘要下面还有一行：`↳` 可拖到时间轴行换父级（单击解除），
  同一行是「跟随位置 / 旋转 / 缩放」勾选（写空间父级的 `inherit`）；相机属性页也有这一行。
- **三轴旋转控件**（`DESIGN-TRANSFORM-UNIFY.md` §2，2b）：
  - 时间轴：2D 节点、3D 物体、相机各三行 `旋转 X°/Y°/Z°`，每行独立输入、独立菱形、独立属性链接。
  - 属性面板：2D 节点 / 3D 物体 / 相机都是 `X/Y/Z` 三格，单元格里的 `↳` 链接 `rotation.x/y/z`；
    旋转球保留，拖动后一次写回三个角（`rotationFromDirRoll` 保留当前画面内自转）。
  - 视口：选中 3D 物体时，枢轴处画 X/Y/Z 三个旋转环，拖动按屏幕角度改对应轴；有该轴关键帧时写当前帧，
    否则写基础旋转。相机路径 gizmo 暂不提供旋转环。
  - 第一次给只有 `dir/roll` 的老宿主写旋转时，先按当前姿态换算 `rotation` 基础值再写键，避免第一帧跳。
  - 旧 2D 元素在 2c 自动迁移成节点之前仍是旧的单行「旋转」；迁移后自动变成三行三格。
  - 相机旧的「手动 roll」打开工程时并进 `rotation.z`，时间轴不再单独列出这一行。
- **新建/插入元素**：文字/色块/图片/视频/声音/3D 默认从播放头所在帧的左边界开始，默认 5s
  （图片 5s，视频/声音按源时长，未知回退 5s）；项目自动延长。有选中行时插到选中行上方，
  无选中时插到列表最上方并选中；顶部插入平滑滚到顶部，筛选隐藏新行时清筛选。
  顺序和 2D z 在同一个 batch 中写入，一次创建 = 一次撤销。
- **相机属性页**：多台相机可同时展开，展开立即渲染（不等待 `activateCamera` op）；选中/激活另一台
  相机不会折叠已展开页；每台相机的位置行独立读写自己的 path，相机行之间仍按 `cameraOrder`。
  选中相机时，属性页的「这台相机的投屏」列出所有以它为来源的投屏元素（延迟一帧会标出），
  点「飞到」把编辑视角移到那块投屏前（不跟随）。
- **跟随相机与投屏导航**（`DESIGN-TRANSFORM-UNIFY.md` §1.4）：
  - 选中相机按 `F5`，或右键相机「跟随此相机」：进入编辑视口的选择模式，视角逐帧跟随这台相机；
    播放头不在镜头时间段内时先跳到镜头起点；播放到镜头末尾自动暂停。切到移动模式即脱离，
    自由相机从当前机位继续。末尾暂停后再按空格 = 从镜头起点重播（不自动切下一台相机）。
  - 跟随只覆盖镜头自己的时间段。把播放头拖到 `[起点, 终点]` 之外会结束跟随并暂停：
    视角停在最近的镜头首帧/末帧机位，工具栏的跟随角标消失，toast 提示；想再看就重新 `F5`。
    恰好停在终点不算离开（那是自动暂停的位置），角标显示「末尾」。
  - 编辑视口双击投屏、预览双击投屏、时间轴右键投屏「跟随投屏来源」、属性面板投屏的「来源相机 [跟随]」：
    跟到这块投屏的来源相机（双击会同时选中来源相机）。文字压在投屏上时，最上层的文字优先，
    双击仍然编辑文字。
  - 按住 `F3`：高亮当前视野里的投屏平面（边框 + `投屏 · 来源相机名`；延迟一帧另标「上一帧」）。
    进不去投屏画面里嵌套的投屏，需要先跟随外层来源相机。
  - 没有面包屑，也没有视角后退键；按 `F5` 跟另一台相机、或退出编辑视口即可换画面。
- **帧级播放头**：红线/高亮按帧左边界显示；标尺在帧宽足够时显示帧刻度，主刻度 ≥1s 对齐整秒，
  时间码帧号按 floor。红线右侧的当前帧 band 在每个 track 内、片段下方、行背景上方；帧宽
  <0.5px 时隐藏。拖标尺/剪刀把 seek 量化到帧，播放/预览仍用原始时间。
- **写入贴帧**：片段移动、左右裁边、新打的关键帧（时间轴 ◆、属性面板 ◆、属性输入框写键）都写「帧左边缘」，
  时间按 3 位小数**向上**取整（`timeline-math.js::frameKeyTime`；直接 round3 在 7/30、11/24 这类帧会被顶回上一帧）。
  先磁吸（0 / 结尾 / 节拍）再落帧，按住 Alt 关闭磁吸后仍落帧；项目结尾保留精确 duration，
  素材结尾按源时长保留精确值。旧项目已有的非整帧关键帧不批量重写，只有新建/拖动的键贴帧。
  打开旧项目时，所有元素 / 3D 物体 / 相机片段的头尾一次性对齐到最近帧（`core/clip-frames.js`，
  只改片段窗口，不动关键帧）；因为这是内存迁移，保存前会提示，且首次保存会先把旧文件
  备份到 `.vdm/backups/project-<rev>-<timestamp>.vdm.json`。
- **元素框选**：画面空白处拖动出选框，2D 元素四边形 / 3D 物体投影包围盒与选框相交即选中；
  Ctrl/Cmd/Shift + 拖框在现有选择上加选。左下元素列同样支持：从未选中的行起手拖动框选；
  已选中的行拖动仍是调整顺序。所有选中元素用同一档底色/描边，primary（新加选的）稍亮一档。
- **关键帧选择**：Ctrl/Cmd 点击菱形从空选区 0→1 加选，再点切换；框选覆盖 2D（`data-el`）、相机
  和 3D 关键帧。普通拖框替换当前键；Ctrl/Cmd/Shift + 拖框**切换**框内菱形（未选加选、已选取消），
  框外不变。从轨道、section 名称栏或属性名称栏起手都可：名称栏点按仍执行原来的选择/折叠，
  拖动 >3–4px 才进入框选；不会选中列表文字；框选后保留 primary 的 host 行。
- **视口混选**：Ctrl/Cmd/Shift 点画面里的 2D 元素或 3D 物体进入同一个元素池（再点切换掉）；
  Ctrl 点空白不清空。普通点选仍是替换。
- 片段（clip）：一行文字，名称省略；片段宽度 < 90px 时隐藏右侧附加信息（如「9 关键点」），不换行。
- 颜色见 §3.3；选中片段 1px `--accent` 描边 + 外发 1px 淡青；关键帧菱形 7px，当前帧 9px 实心 `--keyframe`。
- 播放头 2px `--playhead`，顶部三角；切开按钮跟随播放头（现有行为保留）。

## 6. 交互规则

- **单一选中模型**：舞台、时间轴、图层、属性面板的选中都走 `main.js::select()`；任何面板不得维护自己的「当前对象」。
- **单击选中，双击进入/执行**（编辑文字、跳到起点、加入素材）。拖动阈值 3px，阈值内算单击。
- **右键** = 该对象的上下文菜单；菜单项与命令面板同名同快捷键。
- **破坏性操作**：可撤销的直接执行并 toast「已删除…（Ctrl+Z 撤销）」；影响多个对象且不易恢复（如删父级）才弹确认。
- **焦点**：`:focus-visible` 一律 `--focus-ring`；鼠标点击不显示焦点环。文本输入获得焦点时，单字母快捷键失效；
  `F2`、`Esc`、`Ctrl+K`、`Ctrl+Z` 仍有效。
- **禁用**：尽量不用禁用按钮；动作当前做不了时允许点击，用 toast 说明原因（例如「播放头不在镜头范围内」）。
  必须禁用时给出原因提示。
- **数值编辑**：拖拽改值实时预览，松手才提交一次 op；输入框里 Enter 提交、Esc 还原。

## 8. 文案

- 界面语言中文。按钮动词开头、2–4 字（「渲染成片」「新建项目」）；不加句号和感叹号。
- 提示文案 = 名称（+ 快捷键用 `data-kbd`），一句话说明放第二行，不写操作手册。
- toast 写结果：「已在 1.80s 切开镜头「镜头 02」」；错误写原因 + 下一步：「没有 Blender，装好后点重启引擎」。
- 单位：秒 `s`、像素 `px`、米 `m`、角度 `°`、百分比 `%`；时间显示两位小数。
- 空状态是邀请不是道歉：「导入素材」而不是「暂无素材」。

---

## 9. 可访问性

- 文字对比度 ≥ 4.5:1（`--text-3` 在 `--surface-1` 上约 4.8:1）；仅禁用态可低于此值。
- 最小字号 11px；最小点击区 22×22px。
- 图标按钮必须有 `aria-label`；切换按钮用 `aria-pressed`；标签页用 `role="tablist"/"tab"` + `aria-selected`；
  菜单用 `role="menu"/"menuitem"`；模态 `role="dialog"` + `aria-modal="true"`。
