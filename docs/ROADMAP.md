## 工程债 / 已知限制

- 预览与 Blender 的**文字排版**不是逐像素一致（字体度量差异），只能保证字号/行高/对齐语义；
- Blender 侧暂不支持：圆角矩形、描边、文字阴影偏移、每元素独立 FX（只有 glow）；
- `contain` 适配、视频变速、混合模式的 `multiply` 只在预览侧有；
- 撤销历史已持久化，最多 80 个快照并按约 32 MiB 的快照大小预算保留；按操作者选择性撤销尚未实现；
- 单渲染任务队列、无优先级；
- 没有打包（`electron-builder`）与自动更新；
- 节拍分析是启发式（能量/频谱通量），对自由节奏的音乐需要手动校正。

## 外部 agent 与底层架构（已实现）

- 公共应用层：版本前提、请求去重、dry-run、全局历史与崩溃恢复。
- 单项目运行时：CLI / Electron / MCP 共用同一队列，独立任务取消、快照与产物溯源。
- MCP stdio：读取、编辑、历史、素材、出帧 / 出片、任务管理与 PNG 回读。
- 求值轨道索引、计算 worker、预览资源回收、可重建缓存清理与固定规模基准。
- 场景树迁移报告完整保留当前混合模型；场景树仍作为只读实验模型，不会强制切换现有编辑器。

接口文档见 `docs/SPEC-MCP.md`，改造记录见 `docs/ARCHITECTURE-REVIEW.md` 第 8 节。
