## 2. A · 变更集审阅面板（右栏「审阅」标签）

**为什么单开一页**：右栏已有 属性 | AI | 渲染 三页；把审阅塞进 AI 页会让消息流和审阅互相挤。新增一页最省事，
也不改任何现有页的布局。

### 2.1 入口与状态
- 标签顺序：**属性 | AI | 审阅 | 渲染**。审阅页在有 `proposed` 变更集时，标签上显示一个小圆点
  （`--warn`，8px），不抢焦点。
- agent 提交 `proposed` 变更集时**不自动切页**（不打断人），只在标签上点灯；人点灯才切过去。
- 空态：一行弱化文字「暂无待审阅的变更集」+ 最近 3 条已应用变更集的折叠列表。

### 2.2 列表
每条变更集一行（高 30px，与时间轴行头同高）：

```
▸ cs_5578…  agent:dsh   把 01 词2 改成 150 号字并卡到最近拍点    14 处   [待审阅]
```

- 左侧 `▸/▾` 展开；id 用 `--font-mono`、`--text-3`；`actorId` 用 `--text-2`；intent 单行省略（悬停 tooltip 全文）；
- 右侧计数 `14 处`（`--text-3`）+ 状态徽标：
  - 待审阅 `--warn` / 已应用 `--ok` / 已撤回 `--text-3` / 需决定 `--danger`
- 展开后逐条改动（高 28px，与属性行同高）：

```
☑ style.size      230 → 150            [接受] [撤回]
☑ start           0.5 → 0.833
☑ keyframes[0.49] → [0.823]   （12 条合并行，展开看明细）
```

- 每行一个复选框（默认全选）+ 前值 → 后值（数字 `tabular-nums`，删除线标前值）；
- 行尾两个文字按钮：`接受`（`--accent`）、`撤回`（`--danger`，仅已应用的条目）；
- 底部固定操作条（高 36px）：`接受选中 (3)`（primary）、`全部接受`、`全部撤回`、`对比`。

### 2.3 前后对比
点 `对比` 打开模态（`--scrim` 遮罩，`--surface-3` 卡片，宽 `min(1200px, 86vw)`）：
- 左右两张截图（WP2.4 已经产出 `before-*.png` / `after-*.png`），中间一条可拖动的分隔线（`--accent`）；
- 顶部一行元信息：`f33 → f42 · 827×465 · rev 308 → 309`；
- 没有截图时显示「还没有截图」+ 按钮 `截当前帧`（调 WP2.4 的 still，显示 12 s 的进度态，可取消）；
- 底部：`接受整组` / `关闭`。`Esc` 关闭。

### 2.4 数据与错误
- 数据全部来自 WP2.4 已存进 `ai.js` 的 `plan / changesets / report / stills`（`getData()`），**不新增后端读取接口**；
- 接受/撤回调 WP2.2 的 `changeset-service`（`apply` / `revertOne` / `revert`）；
- 冲突（`needs-decision`）时该条展开为一行 `--danger` 文案：`该属性在之后被改过（期望 150，当前 300）`，
  复选框禁用，只留 `查看`；
- 操作失败（`LOCKED` / `PATH_OUTSIDE_SCOPE`）在面板底部显示一行 `--danger` 文字，不弹模态。

## 3. B · 时间线标记

- **标尺**：每个变更集在它触及的最小帧上画一个 8×8 的菱形（`--accent`，与播放头同层但不遮挡），

  撤回后消失。不改行高、不改按钮顺序（眼睛 | 空间父级 | 折叠 | 类型点 | 名称 保持不变）。

## 4. C · 报告工具（点选 / 框选 + 现象标签）

- 快捷键 **`Shift+R`**（不进 `Ctrl` 组合，避免和现有冲突）；顶栏不新增按钮，命令面板里有一条
  `报告问题…`。
- 进入后视口变"取景模式"：光标 `crosshair`，拖一个框（点选 = 3×3 的框），松手弹出轻量浮层（锚在鼠标附近，
  `--surface-3`，宽 320px）：
  - 现象标签（多选，chip）：`重叠` `位置` `颜色` `时间` `闪烁` `其它`
  - 一句话描述（单行输入，`Enter` 提交、`Esc` 取消）
  - 复选框 `附当前帧截图`（默认勾上）
  - 底部：`保存` / `取消`
- 保存后：写一个锚点到 `.vdm/reports/<frame>-<hash>.json`（`{frame, rect, tags, note, still, rev, elementId?}`），
  同时在 AI 页的消息流里插入一张 `--surface-2` 卡片（`报告 f150 · 重叠 · 已附截图`），供 agent 读。
- 视口右下角显示 1.2 s 的 `--ok` 提示「已记录报告」；`Ctrl+Z` 不撤销报告（报告不是项目状态）。

## 5. D · 锁定开关（D4）

- **属性面板粘性头部**：在现有图标按钮（复制、删除）**之前**加一个锁图标：
  - 未锁：`🔓` 弱化（`--text-3`），悬停提示「锁定后 agent 不能改这个元素」；
  - 已锁：`🔒` 实心（`--edit`）+ 头部底色 `--edit-bg`，名称后加一个小标签 `Agent 只读`（`--edit`，10px）。
- **时间线**：右键菜单加一项 `锁定 / 解锁`（`--edit` 图标）；锁定后行名称前出现 `🔒`（不改变按钮顺序）。
- **锁定不挡人**：检查器的输入框仍可编辑（`actorId: ui` 不被 `LOCKED` 拦），已由 WP2.2 保证；界面上只是提示。
- **点选与框选**（要你确认语义，见 §8）：
  - 单击**锁定**元素：仍然选中（否则人无法解锁/改它）；
  - 框选：**跳过**锁定元素（批量操作不会误删/误改被锁的东西），松手后状态栏提示「已跳过 2 个锁定元素」。

## 10. 修订 R1（2026-10-29，B 应用户要求补写）

原则不变：只新增，不改人现有的操作方式。本节按"对用户来说直不直觉"修订 §2–§5，与前文冲突时以本节为准。
现有操作的事实（作为约束）：标尺直接拖 = 移动播放头，Ctrl + 拖 / 滚轮 = 缩放时间轴；编辑模式下单击 Alt = 切换选择 / 移动；
拖片段或关键帧时按住 Alt = 不吸附；单字母快捷键已占用 G、L、S、U、V；Ctrl+Shift+R = 重启引擎。

### 10.1 回答 §8 的三个问题

| # | 问题 | 修订 |
|---|---|---|
| 1 | 锁定元素在视口里怎么处理 | **完全点不中**：单击穿透到下面第一个未锁定的元素，框选也跳过。选中和解锁走时间线、大纲（§10.5） |
| 2 | 审阅单独一页还是并入 AI 页 | **单独一页**（属性 \| AI \| 审阅 \| 渲染）。审阅还要覆盖 MCP、命令行等其他来源的变更，所以不能只挂在 AI 对话下面。AI 对话里的结果卡片能一键跳到对应的变更集 |
| 3 | 报告快捷键 | **Shift+R**。判断时严格排除 Ctrl、Alt、Meta（防止误触 Ctrl+Shift+R 重启引擎）；文本框内、移动态飞行时不触发。另在预览工具栏加按钮，并在视口和时间线右键菜单加"报告这个问题…" |

### 10.2 审阅面板（修订 §2）

1. **按状态给按钮，每种操作只留一个入口**
   - 待审阅：`采纳` / `不要`；已采纳：`撤回`。待审阅状态下不出现"撤回"二字，避免让人以为修改已经生效。
   - 保留"复选框 + 底部操作条"（`采纳选中 (3)`、`全部采纳`、`全部不要`）；每行的按钮只在悬停时出现。
2. **用人话显示改动**
   - 按**元素**分组，组标题是元素名（如"01 词2 幻想"），不显示 `cs_…` 或 `el_…`。id 放进悬停提示。
   - 属性名用契约里的中文 label（WP2.3），如"字号 230 → 150"，不显示 `style.size`。
   - 时间用帧号，和时间线一致，如"起点 f15 → f25"。
   - **一个 op 的连带改动合成一行**，如"整体后移 10 帧（含 2 个关键帧）"。复选框的粒度是 op，不是单个字段，避免只采纳一半把元素弄坏。
   - 来源显示为"AI 助手"或"命令行"，`actorId` 放进悬停提示。
3. **点一行就跳过去**：选中该元素，播放头跳到受影响的第一帧，检查器高亮对应属性。
4. **在画面里预览（新增，最重要）**
   - 审阅页每个待审阅的变更集有 `在画面里预览` 开关。打开后，视口和播放显示"采纳后"的版本（用 WP2.2 的影子工程，不写盘、不占 rev）。
   - 视口顶部显示横幅："正在预览 AI 的修改 · [采纳] [不要] [退出预览]"，横幅颜色用 `--warn`，提醒用户现在看到的不是真实工程。
   - **按住 `\` 临时显示修改前的画面**，松开恢复。键位需确认未被占用。
   - 预览期间禁止编辑（检查器和 gizmo 只读）。用户一动手编辑，就自动退出预览，先回到真实工程。
   - §2.3 的截图对比模态保留，作为补充。
5. **采纳 = 一步撤销**：整组采纳后按 Ctrl+Z 可以直接退回。审阅页的"撤回"用来撤回更早的某一组（选择性撤销）。
6. **提议过期**：提议之后，人又改了同一元素的同一属性，这一行标灰并显示"你之后改过这里（现在 300）"，提供 `仍然采纳` / `让 AI 重新做`。默认不采纳，绝不悄悄覆盖人的修改。
7. **"需决定"不用红色**：改用 `--warn`，直接给两个按钮："保留现在的值（300）" / "用 AI 的值（150）"。
8. **AI 想改锁定元素**：在变更集里显示一行"AI 想把字号改成 150，但这个元素已锁定"，提供 `临时解锁并采纳`（解锁、采纳、再锁回，整个过程算一步撤销）。
9. 审阅页增加 **"报告"分区**，见 §10.4 第 7 条。

### 10.3 时间线标记（修订 §3）

1. **按改动类型标记**，不再统一在"最小帧"画菱形：
   - 改了整段属性（字号、颜色这类与时刻无关的改动）：元素行名称左侧 2px 竖条，整条片段加细描边；
   - 改了关键帧：只在那些关键帧上加外圈；
   - 发生在某个时刻的改动（新增元素、移动起点、切镜点变化）：才在标尺上画菱形。
2. **已采纳的改动也保留淡色标记**，直到用户点 `知道了`（审阅页上，可整组确认），或者手动改了这个元素。用户最想知道的就是"AI 刚才动了哪里"。
3. **专用颜色**：在 `tokens.css` 新增语义 token `--ai`（及 `--ai-bg`），不与选中、播放头使用的 `--accent` 撞色。

### 10.4 报告：报告草稿（修订 §4）

编辑用的选择池（`core/selection.js`）**一次只放一类东西**，这是编辑的需要（删除、移动、检查器都依赖它），**不改**。
报告单独用一个"报告草稿"，像邮件附件一样，什么都能往里放。

1. **数据**：新建 `core/report-draft.js`（纯 ESM）。草稿 = `{ attachments: [{ kind, ref, label }], tags: [], note }`。
   `kind` 包括：`element`、`object`、`camera`、`property`、`keyframe`、`range`、`region`、`changeset`、`cut`。可以混合。
2. **第一次按 Shift+R**：新建草稿，**自动带上当前选中的内容**（不强制在画面上点）。视口右下角出现可收起的小面板"报告草稿"，
   不是模态，不挡操作。这样消失的、被挡住的元素也能报告：从时间线或大纲选中它再按 Shift+R 即可。
3. **草稿开着时再按 Shift+R**：把当前选中的内容（以及时间范围，见 §10.6）**追加**为新附件。面板上也有 `+ 加入当前选中` 按钮。
4. **画面区域**：草稿开着时，在视口里按住 Shift 拖框，框出一块区域作为附件（不对应任何元素也可以）。
5. **附件标签**：悬停时在画面和时间线里高亮对应的东西；点一下就选中它并跳到对应帧；点 × 移除。
6. **症状标签**改为用户的说法（多选）：
   `看不见` `闪烁` `被挡住` `位置不对` `大小不对` `颜色不对` `没卡上拍` `预览和成片不一样` `其它`。
   另有一项独立入口 **"报告编辑器问题"**（命令面板 / 帮助菜单）：附上播放帧率和日志，和内容问题分开，避免 AI 去改工程。
7. **自动附上测量（调用 WP2.1 的测量服务，"对象 + 症状"决定测什么）**：

   | 附件 / 症状 | 自动附上 |
   |---|---|
   | 任何元素 | 这一帧的求值属性、屏幕包围盒、所在相机、当前模式（预览 / 编辑） |
   | 元素 + `看不见` / `闪烁` | 时间范围内逐帧可见性和遮挡者（`coverage`）；没有范围时取前后各 10 帧 |
   | 点 / 区域 + `被挡住` | 该点从前到后的元素栈（`stackAt`） |
   | 两个及以上元素 | 两两之间谁在前、间距、哪些帧里有遮挡 |
   | 关键帧 + `没卡上拍` | 离最近拍点差几帧 |
   | `预览和成片不一样` | 提交时后台出一张 Blender 帧并与预览做差（走任务系统，可取消） |
   | 时间范围 + 任意 | 范围内的切镜点（`cutEdges`） |

   测量结果写进报告文件；耗时较长的项（Blender 出图）在后台补上，报告先保存。
8. **提交后**：报告写入 `.vdm/reports/<id>.json`（字段在原 §4 基础上加 `attachments`、`measures`、`camera`、`mode`、`status`），
   AI 页插入卡片，**审阅页"报告"分区**列出全部报告及状态（待处理 / 已修 / 已验证）。
   AI 修完后，报告上有 `重新测量` 按钮：在同一组附件上重跑同一组测量，数据达标才能标为"已验证"。
9. **本期（WP2.5）支持的附件**：元素、3D 物体、相机、属性、关键帧、时间范围、画面区域、变更集。
   以下标为后续，不在本期：切镜点、音频和拍点、全局效果和环境、属性链接和父子关系、代码图层（R3）、来自网页的元素（R4）、效果预设。

### 10.5 锁定（修订 §5）

1. **语义与通用软件一致**：锁定 = 视口里点不中、拖不动，AI 不能写入。
   - 视口单击**穿透**：点到锁定元素时，选中它下面第一个未锁定的元素；框选跳过锁定元素。
   - 时间线、大纲里仍可选中锁定元素；选中后检查器照常可改值（`actorId: ui` 不受 `LOCKED` 拦截）；视口里**不显示可拖动的 gizmo**，只显示选中轮廓。
   - 去掉 `Agent 只读` 小标签。锁图标的悬停提示写："已锁定：视口里不能点选拖动，AI 不能修改"。
2. **开关位置**：
   - 时间线行：锁定后，名称前显示锁图标，**点它直接解锁**；未锁定的行在悬停时显示一个淡色锁图标，点了就锁上（不改变现有按钮顺序，图标只占名称前的位置）；
   - 属性面板头部和时间线右键菜单：保留原方案的入口。
3. **用项目图标集**（`icon()`），不用 emoji 🔒🔓。
4. **不向子级传递**：锁父级不会锁住子级（第一版），在 `docs/DESIGN.md` 里写明。

### 10.6 时间范围选择（新增）

1. **鼠标：Shift + 在标尺上拖动**，选出一段时间范围。Alt 不可用（会触发选择 / 移动切换），Ctrl 已用于缩放。
   范围吸附到整数帧，显示为标尺上的半透明色带（`--ai-bg` 以外的中性色，如 `--surface-3`），两端可以再拖动微调。
2. **键盘：I 设起点，O 设终点**，都取播放头所在帧（与 Premiere、达芬奇的入点、出点习惯一致）。移动态飞行时不触发。
3. **清除**：Esc（按"逐层退出"顺序，先清范围，再取消选中），或点色带上的 ×。
4. **范围是界面状态**：不写进工程，不进撤销历史。
5. **平时也能用**，不限于报告草稿打开时。本期只有报告会用到它；以后"只循环这一段""只导出这一段"可以直接复用，本期不做。
6. 曲线面板（F2）打开时，标尺上的 Shift+拖动和 I / O 同样生效。

### 10.7 验收补充（在 §7 基础上增加）

1. **画面预览**：打开预览后，视口像素等于"采纳后"的工程，按住 `\` 时等于原工程（各读一次 canvas，像素差为 0）；
   预览期间 `project.vdm.json` 的 hash 和 rev 不变；采纳后 rev + 1，一次 Ctrl+Z 回到原 hash。
2. **人话显示**：注入的变更集里不出现 `cs_`、`el_`、`style.` 字样（DOM 文本检查），悬停提示里有。
3. **提议过期**：提议后用检查器改同一属性，该行变为过期状态，`全部采纳` 不覆盖人的值。
4. **报告草稿**：在时间线选一个元素 → Shift+R → I/O 设 f144–f153 → Shift+R → 选"闪烁" → 提交。
   报告文件里有 2 个附件、逐帧 10 条可见性记录；用 miku-swiss 副本的 `s2_w4` / cam_8，结果与 WP2.1 的 `coverage` 输出一致。
5. **锁定穿透**：锁定 `s2_bg` 后在它覆盖的区域单击，选中的是它前面或下面的未锁定元素；时间线里点锁图标能解锁；锁定元素被选中时视口没有 gizmo。
6. **快捷键**：Ctrl+Shift+R 仍然只重启引擎；文本框里输入大写 R 不触发报告。
7. **范围**：Shift+拖标尺得到整数帧范围；直接拖仍然只移动播放头；Ctrl 仍然缩放；Esc 清除范围。

## 11. 落地审查（A 审 R1 后补，2026-10-29）

逐条对着 master `ae0f267` 的代码核实，只记**会改变工作量**的差异；不改 §10 的界面决定。

### 11.1 三条后端面在 R1 里被低估

| 缺口 | 实测 | 补法 |
|---|---|---|
| 变更集 HTTP 面 | 渲染进程只能访问 `/core/*`；`application/changeset-service.js` 是 Node 模块，浏览器里跑不了；`/api/rpc` 要 runtime token 且没有 changeset 方法。**审阅页现在拿不到任何跨进程的变更集**——`ai.js` 的 Map 只在一次 agent 运行内有效，刷新即空 | 新增 `GET /api/changesets`、`GET /api/changesets/:id`、`POST /api/changesets/preview|apply|revert|revert-one`，全部转给 `ChangeSetService`，`actorId: 'ui'` |
| 测量 | `application/inspect-service.js` 只被 agent 和 CLI 用，没有 HTTP 面 | `POST /api/measure`：白名单 `coverage|stackAt|cutEdges|diff|pxAt|pixelCoverage`，参数校验与 agent 的 `measure` 工具同源 |
| 报告存储 | 无 | `POST /api/reports`（写 `.vdm/reports/<id>.json`）、`GET /api/reports`、`POST /api/reports/:id/remeasure`；报告不进 rev、不进撤销 |

### 11.2 server 还在跑 legacy `AgentRunner`

`engine/server.js:253` 仍 `new AgentRunner(...)`：`/api/agent` 收到 `proposal` 后**直接 transact**——没有变更集、没有计划、没有批准。
`ai.js` 已经按 `AgentLoop` 的事件（`plan` / `changeset` / `step`）写好了，生产里却收不到。

所以 2.5a 的前置不是"加一个 approve 路由"，而是**把 `/api/agent` 切到 `AgentLoop`**：

- `POST /api/agent` → `loop.run({ task })`；`POST /api/agent/approve` → `loop.approve({ planId })`（无待批准时 404 `NO_PENDING_PLAN`）；
- `GET /api/agent/state` 返回 `loop.state`，刷新后审阅页仍能看到当前运行与待审阅变更集；
- `AgentLoop` **没有 `cancel()`**（只有 `AgentRunner` 有），`/api/agent/cancel` 会 500：加一个步间中止标志（`cancel()` 置位、`#step` 检查、状态 `cancelled`）；
- `AgentRunner` 留到 2.5a 合并后再删，单独提交、可回退。

### 11.3 画面预览怎么落地（§10.2-4 的实现细节）

不能用 `applyProject(shadow)`：它开头就 `if (p.rev <= S.project.rev) return;`，影子工程 rev 不变，会被直接丢掉。
做法是**只覆盖视口**：

- `S.previewShadow = preview({ includeProject: true }).project`；
- 视口/播放用轻量版 `preview.setOverlay(p)`：只换 `preview.project` + 清 `_irCache`，**不重建纹理/音频**（影子与真实工程共用同一批源）；退出时换回 `S.project`；
- 检查器、时间线、大纲仍读 `S.project`（真实工程）并置只读；`\` 只在内存里把 `preview.project` 指回真实工程，零往返、像素差 0；
- 横幅和"预览期间禁止编辑"由 `S.previewShadow` 一个标志驱动，所有写入口检查它。

### 11.4 另外三件小事

- **过期采纳**：`apply({ id })` 默认用 `record.baseRev`，人改过之后会 `REV_CONFLICT`；"仍然采纳"必须显式传 `expectedRev: 当前 rev`，这条要进 2.5a 的测试。
- **临时解锁采纳**：一次事务里做——内存副本清 `locked` → 跑 ops → 把 `locked: true` 复原 → `replace` 提交；这样 `changed` 里不出现 `locked`，一次 Ctrl+Z 全退。
- **图标**：sprite（`app/renderer/index.html`）里没有 `i-lock` / `i-lock-open`，2.5b 要加；`hitTest` 只返回一个 id，锁定穿透要加 `hitTestAll()`。

### 11.5 快捷键实测

`Shift+R`、`I`、`O`、`\` 都空着；`Ctrl+Shift+R` 的 match 要求 ctrl，不会撞。`S` / `L` / `G` / `V` / `U` 已占用（与 §10 一致）。
报告命令**不能** `global: true`，否则文本框里按 R 会触发。
